# Java coding style reference review

Read the current CartController, MenuController, OrderController and RestaurantController from https://github.com/IT26100757/Foodie/tree/feature/customer/backend/src/main/java/com/foodie/customer/shopping . GitHub commit metadata attributes their latest commits to it26100797. Files were read for style only and were not copied into the new backend. They use descriptive field/method names, explicit constructors, ordinary Spring annotations, validation and direct repository operations, with nested records where appropriate. Some also use streams; readability matters more than eliminating every stream.

The new backend already has simple controller/service/repository/entity responsibilities and meaningful AppUser role inheritance. It was previously simplified from 41 to 22 packages while keeping the five-file limit. No further structural rewrite was needed for a folder reorganization, and backend source is byte-identical to the delivered baseline. Future integration changes should prefer descriptive constructor parameters and clear calculations; avoid controller-to-controller business calls, duplicated pricing, memory-only idempotency or excessive interfaces. The pending requirement to move configured monetary policies into database records remains part of integration work, not completed in this folder update.
